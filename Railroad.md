# Railroad crossing station project

This project is about my train coming and going replica using the SNAP program and the hummingbird kit.

URL: https://snap.berkeley.edu/snap/snap.html#present:Username=lvhs5&ProjectName=U2LR%20Railroad


________________________________________________________________________________________________________________________________________________________________________________________

## Design process

The design process for my train station was using the hummingbird kit as a sort of control station and I used the LED lights as the indicators, I also used the position servo as a gate that goes down when something comes near or the train.


________________________________________________________________________________________________________________________________________________________________________________________
